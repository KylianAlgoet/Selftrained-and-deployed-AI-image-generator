# Documentation rules

- Everything in professional English; never mix Dutch and English.
- Maintain the numbered docs (`docs/00`–`docs/09`), process docs (`docs/process/`), `docs/ai-usage.md`, and `docs/learning-outcome-traceability.md`.
- Process-log entries include: date, objective, plan, completed work, unfinished work, blockers, decisions, commands/tests, real results, evidence, commits, next step.
- Planning (`docs/02-planning.md`): preserve the original plan; record every meaningful adjustment with its reason, estimated vs. actual effort, and completion dates.
- Learning-outcome traceability: map concrete evidence (files, experiments, commits) to D1–D7 as it is produced, not retroactively at the end.
- Document Claude Code usage honestly in `docs/ai-usage.md`: what the AI assisted with, what the student decided, and how results were independently verified.
- After every milestone, produce the standard milestone report (MILESTONE / STATUS / BRANCH / RESEARCH QUESTION OR HYPOTHESIS / WORK COMPLETED / FILES CHANGED / TESTS AND VALIDATION / ACTUAL RESULTS / EVIDENCE / DECISIONS / COMMITS / RISKS OR BLOCKERS / PLANNING CHANGES / NEXT ACTION).
