Decals are 1:3. The deck surface is 1:3.9. **Both options were built and compared.** The interface
tells the user which one it chose, and that the artwork is stretched.

## Speaker notes

A small thing that shows how the decisions were made.

Decals are one to three. The deck surface is one to three point nine. Something has to give.

I built both options rather than picking one. Stretch to fill, which distorts the artwork about
thirty per cent vertically. Or preserve the ratio, which leaves a quarter of the board bare.

I chose to fill, because a graphic that covers the deck reads as a finished product and one with a
bare strip reads as a bug.

The part I would defend is the last line: the interface says so. It tells the user the artwork is
stretched, in the panel, rather than hoping nobody measures it. A trade-off the user is told about
is a design decision. The same one hidden is a defect waiting to be found.
